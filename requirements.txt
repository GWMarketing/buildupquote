# pdfkit is just a thin Python wrapper -- it calls a real program called
# wkhtmltopdf to do the actual HTML -> PDF rendering. `pip install pdfkit`
# does NOT install that program; it's a separate, system-level install:
#   - Mac:     Homebrew's cask for this was removed (the upstream project is
#              unmaintained), so `brew install --cask wkhtmltopdf` no longer
#              works. Instead, download the .pkg installer directly from
#              https://github.com/wkhtmltopdf/packaging/releases and run it
#              like any other Mac installer. It's built for Intel; on Apple
#              Silicon (M1/M2/M3/M4) macOS will prompt to install "Rosetta"
#              the first time it runs -- let it, that's expected.
#   - Windows/Linux:  download the installer from wkhtmltopdf.org
# If "Download Proposal PDF" in the app errors out, this is almost
# certainly why -- install wkhtmltopdf, then restart the app (stop it with
# Ctrl+C in the terminal and run `streamlit run app.py` again).
